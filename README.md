# Government Graphic Assets

This repository contains the official graphic assets, branding elements, and visual resources for the government. It is organized to centralize all materials needed for institutional identity, web design, public communication, and digital publishing.

## Repository structure

The repository currently includes the following main folders:

### 1. Brand Identity

This folder groups the foundations of the official visual identity.

- `logo/` : Official logos in different formats, including horizontal, vertical, monochrome, dark, and light versions.
- `emblem/` : Official emblem, coat of arms, and institutional seal assets.
- `flag/` : National or institutional flags in vector and raster formats, adapted to different aspect ratios.
- `charter/` : Graphic identity charter including usage rules, spacing, color requirements, and protection zones.

### 2. Typography

This folder stores type-related assets and specifications.

- `latin/` : Latin-script typefaces in formats such as TTF and WOFF2.
- `tifinagh/` : Official Tifinagh typefaces and supporting font files.
- `fonts-spec/` : Typography rules including font sizes, weights (regular, bold), line spacing, and alignment standards.

### 3. Media

This directory contains media assets for communication and publication.

- `photos/` : Official photographs including portraits, monuments, landscapes, and institutional settings.
- `social/` : Visuals optimized for social media platforms such as X/Twitter, LinkedIn, and Facebook.
- `press/` : Media kits, press visuals, and communication assets prepared for public announcements.

### 4. UI Assets

This section supports web interfaces and digital product design.

- `icons/` : Site and interface icons in SVG format for navigation, actions, and status indicators.
- `banners/` : Header banners, hero visuals, backgrounds, and page cover graphics.
- `illustrations/` : Vector illustrations and editorial graphics for layout and presentation.
- `favicons/` : Browser icons in `.ico` and PNG formats for different dimensions.

### 5. Guidelines

This top-level folder provides rules and reference documentation for the correct use of the brand system.

- Brand usage policies
- Editorial and visual standards
- Content and accessibility guidance
- Reference templates and implementation notes

## Purpose

The goal of this repository is to ensure consistent visual identity, centralized asset management, and efficient reuse across government digital platforms and communication channels.

## Best practices

- Use vector files whenever possible for scalability and adaptation.
- Respect logo clear space and brand usage restrictions.
- Prefer official typography files and approved media assets before creating custom variants.
- Store files in formats suited to their final use: web, print, social, or presentation.

## Notes

This repository acts as the official graphic asset library for institutional communication. All files should be used in accordance with the government brand policy and the applicable design standards.
